# BioMaker 桌面版快速开始

当前安装包适用于 Apple 芯片的 Mac（M1 / M2 / M3 / M4 等）。

## 安装与首次配置

1. 打开 `BioMaker-0.1.4-mac-arm64.dmg`，将 BioMaker 拖入 Applications。
2. 从应用程序文件夹打开 BioMaker。
3. 在首次引导中点击「安装」准备运行环境。Python 已随应用提供，训练依赖会自动下载；无需自行安装 Python、Node 或 Homebrew。
4. 打开「设置 → 模型服务」，填写你的 API 地址、API Key 和模型名称。可以点击「连接并获取模型」检查连接。兼容 OpenAI API 的服务都可以填写；使用 OpenAI 时 API 地址可留空。
5. 保存配置，点击「返回实验」继续填写原来的实验草稿。填写不完整时，设置会提示还缺少哪一项。

模型配置尚未保存时，关闭窗口或退出应用会提示继续编辑或放弃更改。保存过程中请等待请求结束；保存失败后，已输入的内容会保留，方便重试。

首次下载训练依赖需要网络和数 GB 可用空间，可以查看安装日志或取消后重试。模型调用由你配置的服务计费。

当前版本已做本机临时签名，尚未做 Apple Developer ID 签名与公证。从网络获得安装包时，macOS 可能要求在「系统设置 → 隐私与安全性」中确认打开。请仅使用你确认来源的安装包，无需关闭系统安全保护。

## 开始一个实验

选择数据集文件夹，写清楚任务、标签、训练/验证划分和评估指标。界面提供「图像分类」「医学图像分割」「快速基线」作为可编辑的起点。

通过「高级设置」调整探索步数、单次执行超时、探索时长、并发数、最终重训以及模型。快速基线默认只运行 3 步、1 个并发进程、探索时长上限 30 分钟，并关闭最终重训；探索时长不包含数据准备、最终重训与报告，正在进行的请求也可能延后结束，因此不是整个实验的完成时间保证。

运行中可以查看活动、候选方案、代码、日志和输出文件。任务按数据集组织；失败或停止后，已生成的记录仍然保留。排队暂停时，先阅读原因，再选择继续队列。

## 导入已有实验

在「全部实验」中点击「导入已有实验」，选择单个实验目录，或包含多次实验的 `logs` 目录。预览会列出名称、日期、可查看的内容、文件大小及无法导入的原因；选中需要的实验后点击「导入所选实验」。

应用只复制预览列出的记录文件，包括候选方案、代码、报告、指标和日志。原文件保持不变，数据集、工作目录、模型权重和子目录不会复制。导入不需要安装训练环境或配置模型服务。

导入的记录仅供查看，不能停止或重新运行原实验。没有结束事件的记录会显示为历史快照；它不能说明原实验是否仍在运行。相同来源再次导入会保留已有副本。源文件在预览后变化时，需要重新扫描；服务中断后可以查看导入记录并继续处理未导入的实验。

## 文件与运行状态

实验数据默认保存在 `~/Library/Application Support/BioMaker/`，可以在「设置 → 运行环境」中打开工作区。选择数据集不会把整个数据集复制到应用里。

启动时会显示「正在启动本地服务」，临时中断时会显示「正在重新连接」。连接恢复后会自动刷新，实验草稿和未保存的模型配置会保留。

关闭窗口不会停止已经运行的实验。退出桌面应用后，已经启动的实验由独立的队列进程管理；重新打开应用后可以查看它们。需要停止时，请使用实验详情中的「停止」。电脑睡眠会影响本机计算。

「设置 → 通用」可开关实验完成或失败提醒。应用在后台运行或仅关闭窗口时可以通知；完全退出应用后不会通知。通知需获得系统许可，点击后会打开对应实验，通知内容不展示数据集或任务名称。

仅更新界面时，应用会复用源码、平台和 Python 版本匹配的训练环境。引擎代码改变时会准备独立环境，并保留旧环境，避免影响已有任务。

「文件」标签支持预览文本、代码和报告，并通过系统保存窗口导出文件。候选指标来自该实验的记录，不能替代独立测试或临床验证。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| ⌘ N | 新建实验 |
| ⌘ K | 搜索实验 |
| ⌘ , | 设置 |
| ⌘ B | 展开 / 收起侧栏 |
| ⌘ Enter | 提交准备好的实验 |
| Esc | 关闭当前对话框 |

「设置 → 通用」中的语言会同时切换应用界面、系统菜单和原生文件对话框，并在下次打开时保留。

当前版本优先验证 macOS Apple 芯片。Windows、Linux 和远程 GPU 连接将分别验证，不能由桌面界面可移植推断训练引擎已经跨平台验收。
