# BioMaker 桌面版快速开始

当前安装包适用于 Apple 芯片的 Mac（M1 / M2 / M3 / M4 等）。

本页对应 0.1.11；安装包和安装升级的验收进度见 [验收记录](ACCEPTANCE-0.1.11.md)。

## 安装与首次配置

1. 打开 `BioMaker-0.1.11-mac-arm64.dmg`，将 BioMaker 拖入 Applications。
2. 从应用程序文件夹打开 BioMaker。
3. 在首次引导中点击「安装」准备运行环境。Python 已随应用提供，训练依赖会自动下载；无需自行安装 Python、Node 或 Homebrew。
4. 打开「设置 → 模型服务」，填写你的 API 地址、API Key 和模型名称。可以获取模型列表，或手动填写模型 ID；使用 OpenAI 时 API 地址可留空。
5. 保存配置，点击「返回实验」继续填写原来的实验草稿。填写不完整时，设置会提示还缺少哪一项。

模型配置尚未保存时，关闭窗口或退出应用会提示继续编辑或放弃更改。保存过程中请等待请求结束；保存失败后，已输入的内容会保留，方便重试。

点击「测试模型响应」可用当前填写的设置发送一次固定短文本。测试可能产生少量 API 费用，不会发送实验任务或数据集，不会保存配置或创建实验；无需先安装训练环境。获取模型列表、保存配置和模型测试分别显示结果，获取到模型名称并不代表该模型能生成回答。

更换 API 地址、密钥或模型后需要重新测试。地址改变时，测试不会把原服务的已保存密钥发送到新地址；请为新服务填写密钥。测试通过只说明该模型当时能响应短文本，不能保证完整实验或所有模型功能都可用。测试失败后，根据提示检查密钥、模型权限、余额、服务地址或网络，再主动重试。

更换 API 地址后，保存前需要填写新地址的密钥，或明确移除原密钥。留空不会把原服务的密钥转用于新地址；移除后可以保存未完成的配置，补充密钥后再运行实验。地址未改变时，密钥栏留空仍会保留已保存的密钥。

如果配置已在其他位置改变，或服务重启导致保存结果无法确认，应用会保留当前输入并要求查看最新配置。核对最新地址、模型和密钥是否已配置后，可以载入已保存的设置，或保留输入继续编辑。继续编辑不会立即覆盖配置；确认后仍需单独点击保存。

首次下载训练依赖需要网络和数 GB 可用空间，可以查看安装日志或取消后重试。模型调用由你配置的服务计费。

当前版本已做本机临时签名，尚未做 Apple Developer ID 签名与公证。从网络获得安装包时，macOS 可能要求在「系统设置 → 隐私与安全性」中确认打开。请仅使用你确认来源的安装包，无需关闭系统安全保护。

## 开始一个实验

选择数据集文件夹，写清楚任务、标签、训练/验证划分和评估指标。界面提供「图像分类」「医学图像分割」「快速基线」作为可编辑的起点。

选择目录后可以查看本机文件概览：普通文件数量、逻辑大小、文件类型及少量顶层条目。概览只读取文件元数据，不打开文件内容、不解压、不调用模型；文件数量不等于样本数，也不代表标注、划分或数据质量已通过验证。

目录很大、子目录无法读取或扫描达到限制时，会显示部分概览。内部符号链接不会被跟随；只有符号链接的目录也不会被当成空目录。若目录已不存在、根目录无权访问或已确认没有文件，请更换目录或刷新。恢复的草稿提示需要授权时，通过「更换」重新选择该目录。

提交实验和重新运行时会重新检查数据目录。检查反映当时的文件系统状态；排队期间移动目录、卸载磁盘或更改权限仍可能导致后续运行失败。

通过「高级设置」调整探索步数、单次执行超时、探索时长、并发数、最终重训以及模型。快速基线默认只运行 3 步、1 个并发进程、探索时长上限 30 分钟，并关闭最终重训；探索时长不包含数据准备、最终重训与报告，正在进行的请求也可能延后结束，因此不是整个实验的完成时间保证。

运行中可以查看活动、候选方案、代码、日志和输出文件。任务按数据集组织；失败或停止后，已生成的记录仍然保留。排队暂停时，先阅读原因，再选择继续队列。

## 查看和保存结果

打开已结束的实验时，默认显示「结果」页；正在运行的实验默认显示「活动」。结果页汇集实验报告、保存的方案代码、候选指标表和最终重训记录，也可以通过「查看全部文件」打开完整文件列表。

「运行记录中的选择」来自实验保存的选择事件；只有代码能够对应时，会标为「与保存代码匹配的候选」。点击「查看候选方案」可打开对应方案的说明、代码和执行输出。缺失、损坏或互相矛盾的记录会显示为无法确认，不会根据报告文字或一个较大的分数推定最终方案。

最终重训单独显示状态。重训结果文件标记成功、只有活动记录而缺少结果文件、配置明确未启用，以及记录暂不可用，都有不同提示。导入的历史快照可能没有包含重训结果文件或模型权重；这不等于原实验重训失败。候选指标来自实验记录，生成的报告是文字总结，请结合原始文件判断，不能据此替代独立测试或临床验证。

点击「预览」可查看不超过 500,000 字节的 UTF-8 文本、代码或报告。在预览中点击「保存文件」，应用会通过系统保存窗口导出原始文件，并核对内容与本次预览一致。如果文件已经更新或本地服务发生变化，请先「重新预览」；校验失败时，已有的目标文件不会被替换。较大文件或无法作为文本预览的文件，可以直接从文件列表保存。

同一时间只能保存一个实验文件。系统保存窗口确认后，关闭预览不会取消正在进行的保存；请等待保存结束再保存另一个文件。重复操作不会自动排队，也不会在稍后覆盖另一次导出。

## 导入已有实验

在「全部实验」中点击「导入已有实验」，选择单个实验目录，或包含多次实验的 `logs` 目录。预览会列出名称、日期、可查看的内容、文件大小及无法导入的原因；选中需要的实验后点击「导入所选实验」。

应用只复制预览列出的记录文件，包括候选方案、代码、报告、指标和日志。原文件保持不变，数据集、工作目录、模型权重和子目录不会复制。导入不需要安装训练环境或配置模型服务。

导入的记录仅供查看，不能停止或重新运行原实验。没有结束事件的记录会显示为历史快照；它不能说明原实验是否仍在运行。相同来源再次导入会保留已有副本。源文件在预览后变化时，需要重新扫描；服务中断后可以查看导入记录并继续处理未导入的实验。

## 整理与复用实验

在实验详情中点击「重命名」，可填写中文或其他显示名称；原名称、输出目录和实验文件都不会改变。搜索可使用显示名称或原名称。同一实验在其他位置被修改时，会保留你的输入并展示最新名称，再次保存才会覆盖。

已经结束的实验可以「归档实验」，在「全部实验 → 已归档」查看并恢复。归档不会删除文件。正在运行或清理的实验会继续显示在当前实验中。

点击「复用为新实验」会将任务和支持的设置填入可编辑草稿。已有草稿时，可以选择保留或明确替换。检查数据集、模型与预算后，点击「开始」才会创建新实验；导入的历史记录需要重新选择本机数据集。

## 文件与运行状态

实验数据默认保存在 `~/Library/Application Support/BioMaker/`，可以在「设置 → 运行环境」中打开工作区。选择数据集不会把整个数据集复制到应用里。

启动时会显示「正在启动本地服务」，临时中断时会显示「正在重新连接」。连接恢复后会自动刷新，实验草稿和未保存的模型配置会保留。

关闭窗口不会停止已经运行的实验。退出桌面应用后，已经启动的实验由独立的队列进程管理；重新打开应用后可以查看它们。需要停止时，请使用实验详情中的「停止」。电脑睡眠会影响本机计算。

「设置 → 通用」可开关实验完成或失败提醒。应用在后台运行或仅关闭窗口时可以通知；完全退出应用后不会通知。通知需获得系统许可，点击后会打开对应实验，通知内容不展示数据集或任务名称。

仅更新界面时，应用会复用源码、平台和 Python 版本匹配的训练环境。引擎代码改变时会准备独立环境，并保留旧环境，避免影响已有任务。

「文件」标签保留全部可用文件的预览和原生保存入口；结果页提供常用结果文件的快捷入口。

## 服务故障与诊断

在「设置 → 运行环境」中点击「检查运行环境」，可检查已安装依赖并执行固定的 CPU 自检。检查不会下载依赖，也不会创建用户实验或调用模型服务。检查失败后，运行环境会停止接受新实验。

点击「修复运行环境」并确认「开始修复」，应用会按锁定版本重新安装依赖、修复本地库，再执行验证。修复可能需要联网下载；已有实验、数据、日志和模型服务设置会保留。检查或修复期间可以取消，并在操作结束后重试。

有实验排队、运行、停止或清理时，需要先等待结束或取消队列，再检查和修复。如果另一个进程仍在维护环境，应用会等待它退出，避免同时修改依赖。

如果本地服务未能启动，应用窗口仍可使用。点击「重试本地服务」即可尝试恢复，当前实验草稿和未保存的模型配置会保留。服务正在启动或自动恢复时，请等待状态更新；重试不会重新提交实验。

在故障提示、设置的「运行环境」，或系统菜单「帮助 → 导出诊断」中，可以将结构化诊断文件保存到本机。文件只包含版本、必要资源可用性和服务状态等检查信息，不包含原始日志、任务内容、API Key、数据文件或用户路径，也不会自动上传。即使本地服务完全未启动，诊断仍可导出。

资源准备持续失败时可重新安装应用，原有工作区位于 Application Support 中。诊断文件不包含原始错误日志；如需自行查看详细日志，可以使用「帮助 → 打开本地日志文件夹」。

## 常用快捷键

| 快捷键 | 操作 |
| --- | --- |
| ⌘ N | 新建实验 |
| ⌘ K | 搜索实验 |
| ⌘ , | 设置 |
| ⌘ B | 展开 / 收起侧栏 |
| ⌘ Enter | 提交准备好的实验 |
| Esc | 关闭当前对话框 |

「设置 → 通用」中的语言会同时切换应用界面、系统菜单和原生文件对话框，并在下次打开时保留。

当前版本优先验证 macOS Apple 芯片。Windows、Linux 和远程 GPU 连接将分别验证，不能由桌面界面可移植推断训练引擎已经跨平台验收。
